# Vendored marks

`github-mark.svg` is GitHub's own mark, taken unmodified from Primer Octicons, which GitHub publishes under the MIT licence.

Source: <https://github.com/primer/octicons>, icon `mark-github-24`.

It is placed rather than redrawn, because a logo traced by hand is an altered logo and both the trademark guidance and the result argue against it. Do not edit this file. To refresh it, fetch the icon again from the upstream repository.

`file-mark.svg` is ours, not vendored. It is a ruled page, and it marks every box in the figure that is a file on disk. It is drawn as an SVG rather than from polylines because the diagram writer paints every block over every polyline, so a drawn glyph would be buried by the box fill, whereas an image is drawn in the pass after blocks.
